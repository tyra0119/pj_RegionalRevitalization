# 訪日外国人 広域誘導シミュレーター

公共交通オープンデータチャレンジ2026 応募作品（テーマ：地方活性化）

**公開URL: https://tyra0119.github.io/pj_RegionalRevitalization/**

> 東京から電車で行けるのに、まだ外国人が来ていない地方

首都圏に集中している訪日外国人を、公共交通で行ける周辺県へ誘導できる余地を、
国土交通省 FF-Data と ODPT の時刻表から可視化・シミュレーションします。

**本作品は行動予測ではなく what-if シミュレーションです。**
「これだけ行きやすいなら、これだけ誘導余地がある」を示すもので、実際の流動を予測するものではありません。

## 画面

1. **現状** — 東京発 → 周辺9県の訪日外国人流動をフローマップで表示。線の太さが流動量、色が鉄道の利用比率
2. **ギャップ** — 到達しやすさ × 流動量の散布図。「近いのに来ていない県」と「来ているのに案内できない県」を並べて示す
3. **シミュレーション** — 東京都内にとどまる流動の一部が周辺県へ分散した場合を、重力モデルで再配分

## 分かったこと

- 東京発 → 他県着の訪日外国人流動は年間 9,979.6 千人。うち周辺9県が 56.9%
- **茨城 37.9 千人・群馬 66.1 千人**。水戸までは77分、高崎までは51分で着けるのに、全国4位の山梨 1,359.6 千人の 1/36・1/21 しかない
- **観光拠点27か所のうち、公共交通の所要時間を算出できたのは19か所**。山梨は3拠点とも算出できない
- 群馬は FF-Data でレンタカー比率が周辺県で最高の15.8%。草津・伊香保へ向かう吾妻線・上越線には特急の時刻表しか無い

## データ出典

| データ | 提供 | 用途 |
|---|---|---|
| [FF-Data（訪日外国人流動データ）2024年](https://www.mlit.go.jp/sogoseisaku/soukou/sogoseisaku_soukou_fr_000022.html) | 国土交通省 | 都道府県間の訪日外国人流動。都道府県粒度の推計値であり実測の移動軌跡ではない |
| [公共交通オープンデータセンター](https://www.odpt.org/) | 公共交通オープンデータ協議会 | 列車時刻表。公共交通オープンデータチャレンジ2026 のデータを使用 |
| [JR東日本 公式時刻表](https://timetables.jreast.co.jp/) | 東日本旅客鉄道 | ODPT に新幹線の時刻表が無いため、新幹線区間のみ補完 |
| [地理院タイル・住所検索API](https://maps.gsi.go.jp/development/ichiran.html) | 国土地理院 | 背景地図と、ODPT に無い駅の座標 |

本アプリケーションが利用する公共交通データは、公共交通オープンデータセンターにおいて提供されるものです。
公共交通事業者により提供されたデータを元にしていますが、必ずしも正確・完全なものとは限りません。
本アプリケーションの表示内容について、公共交通事業者への直接の問合せは行わないでください。

## 算出条件

- 平日 9:00 に東京の主要ターミナル（東京・新宿・池袋・上野・渋谷・浅草）を出発した場合の最早到着
- 乗換は一律5分、一般化費用は「到着までの時間 ＋ 10分 × 乗換回数」
- 経路探索は Connection Scan Algorithm。乗換回数は最も早く着く経路のもので、最小化された値ではない
- ODPT に時刻表が無い路線（中央本線・富士急行線・箱根登山線・御殿場線など）は算出できない。
  算出できない拠点は散布図の「算出不可」帯に置いている
